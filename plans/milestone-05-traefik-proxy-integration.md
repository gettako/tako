# Milestone 05: Traefik Reverse Proxy & Network Routing

---
- **ID**: `M05`
- **Status**: `completed`
- **Blocking**: `[M03]`
- **Target**: Configure Traefik v3 as dynamic reverse proxy in Docker Compose. Configure HTTP/HTTPS traffic routing, Let's Encrypt SSL automation (ACME), dynamic YAML file provider, and standard container labels generated by the Agent.
---

## Acceptance Criteria
- [x] Traefik runs in Docker Compose with Docker provider (`/var/run/docker.sock`), File provider (`/etc/traefik/dynamic`), and bridge network `tako-network`.
- [x] Traefik manages ports `80:80` and `443:443`, dedicated to user application routing.
- [x] `tako-console` runs primarily on port `:3000`, with low-priority fallback router on ports 80/443.
- [x] gRPC port `:50051` bypasses Traefik; exposed directly by `tako-server` container.
- [x] On Worker Nodes: Local Traefik detects application containers deployed by Agent via dynamic YAML files and Docker labels.
- [x] Automated ACME / Let's Encrypt certificate issuance on ports 80 & 443.
- [x] Agent generates dynamic Traefik configurations and standard container labels.
