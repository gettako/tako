# Security Policy

## Supported Versions

We provide security updates for the active release branch of Tako.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Security is a top priority for Tako. If you discover a vulnerability in this project, **please do not report it via a public GitHub issue**.

Instead, please send an email to **security@gettako.dev**. We will acknowledge your report within 48 hours and provide status updates until the issue is resolved.

When reporting a vulnerability, please include:
* A detailed description of the vulnerability.
* Clear steps to reproduce the issue.
* Potential security impact (for example, remote code execution, unauthorized access, secrets exposure).
* Any suggested mitigations if available.

Thank you for helping keep Tako secure.
