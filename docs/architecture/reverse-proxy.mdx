## Why Traefik v3?

Tako uses [Traefik v3](https://traefik.io) as its native edge reverse proxy across both master and worker nodes because:

1. **Native Hot-Reloading Without Process Restarts:** Traefik uses a declarative file watcher. Modifying a dynamic `.yml` configuration file updates routing tables in memory within milliseconds without restarting Traefik or closing active TCP connections.
2. **First-Class Let's Encrypt ACME:** Traefik natively resolves and renews SSL/TLS certificates via the ACME HTTP-01 and TLS-ALPN-01 challenges.
3. **Full HTTP/2, HTTP/3 & WebSocket Support:** Real-time log streams, SSE endpoints, and interactive container terminal WebSockets work out of the box without special proxy buffering flags.

## Static Configuration

When Tako is installed, the static configuration is written to `/etc/tako/traefik/traefik.yml`:

```yaml
global:
  checkNewVersion: false
  sendAnonymousUsage: false

api:
  dashboard: false

providers:
  docker:
    exposedByDefault: false
    network: tako-network
    watch: true
  file:
    directory: /etc/traefik/dynamic
    watch: true

entryPoints:
  web:
    address: ":80"
  websecure:
    address: ":443"

certificatesResolvers:
  letsencrypt:
    acme:
      email: "admin@gettako.dev"
      storage: "/acme.json"
      httpChallenge:
        entryPoint: web
```

## Dynamic Configuration File Layout

The agent atomically writes routing rules for each service inside `/etc/tako/traefik/dynamic/`:

```text
/etc/tako/traefik/dynamic/
├── tako.yml             # Tako Console and master API routing
├── srv_auth_svc.yml     # User Service A router and load balancer
└── srv_api_svc.yml      # User Service B router and load balancer
```

### Sample Generated Service Route:

```yaml
http:
  routers:
    srv-production-secure:
      rule: "Host(`api.yourdomain.com`)"
      entryPoints:
        - websecure
      tls:
        certResolver: letsencrypt
      service: srv-production

    srv-production-redirect:
      rule: "Host(`api.yourdomain.com`)"
      entryPoints:
        - web
      middlewares:
        - redirect-to-https
      service: srv-production

  middlewares:
    redirect-to-https:
      redirectScheme:
        scheme: https
        permanent: true

  services:
    srv-production:
      loadBalancer:
        servers:
          - url: "http://tako-srv-abc1234:8080"
```

## Ingress Traffic Logs & Monitoring

Traefik logs all inbound requests, response status codes, client IP addresses, and upstream latency.
Tako reads these logs directly, parses incoming traffic, and surfaces:
- Requests per second (RPS) and error rate metrics.
- Ingress logs viewer with status code filtering (`2xx`, `3xx`, `4xx`, `5xx`).
- Detailed request inspector sheet showing user agents, upstream response time, and TLS cipher details.
