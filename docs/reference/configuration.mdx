---

## Master Server (`tako-server`)

| Environment Variable | Default | Description |
| :--- | :--- | :--- |
| `TAKO_HTTP_PORT` | `8080` | Port for the REST & SSE HTTP API. |
| `TAKO_GRPC_PORT` | `50051` | Port for the gRPC agent control plane. |
| `TAKO_DB_PATH` | `/data/tako.db` | Filesystem path for the embedded SQLite database file. |
| `TAKO_AUTH_SECRET` | *(Random)* | Secret key used to sign and verify session JWTs and tokens. |
| `TAKO_AGENT_SECRET` | *(Random)* | Master enrollment secret for authenticating connecting worker agents. |
| `TAKO_INITIAL_ADMIN_EMAIL` | `admin@gettako.dev` | Email address for initial superadmin account creation. |
| `TAKO_INITIAL_ADMIN_PASSWORD` | `admin123456` | Initial superadmin password (hashed upon first startup). |
| `TAKO_ENV` | `development` | Set to `production` in production deployments. |

---

## Worker Agent (`tako-agent`)

| Environment Variable / Flag | Default | Description |
| :--- | :--- | :--- |
| `TAKO_MASTER_URL` | `127.0.0.1:50051` | Master server gRPC address (`<master-ip>:50051`). |
| `TAKO_ENROLL_TOKEN` | *(Required)* | Enrollment token to authenticate against master server. |
| `TAKO_NODE_NAME` | `$(hostname)` | Human-readable identifier for this node in the cluster. |
| `TAKO_NODE_ROLE` | `worker` | Role of this node (`leader` on master node, `worker` on remote nodes). |
| `TAKO_PUBLIC_IP` | *(Auto-detected)* | Public IP address of the node (used for domain DNS suggestions). |
| `TAKO_IP_ADDRESS` | *(Auto-detected)* | Internal/private IP address used for cluster communication. |
| `TAKO_STATE_FILE` | `/data/agent.json` | Path to persist local node credentials and session tokens. |
| `TAKO_METRICS_INTERVAL` | `3s` | Interval for collecting and reporting CPU, RAM, and disk telemetry. |
| `TAKO_TRAEFIK_DYNAMIC_DIR` | `/etc/tako/traefik/dynamic` | Directory where dynamic Traefik routing YAML files are generated. |
| `TAKO_INSECURE` | `false` | Set to `true` to disable TLS verification for gRPC in local dev. |

---

## Web Console (`tako-console`)

| Environment Variable | Default | Description |
| :--- | :--- | :--- |
| `TAKO_SERVER_URL` | `http://tako-server:8080` | Upstream backend URL for the Next.js API proxy (`/api/v1/*`). |
| `PORT` | `3000` | Port for the Next.js HTTP server. |
| `HOSTNAME` | `0.0.0.0` | Hostname to bind the console server. |
