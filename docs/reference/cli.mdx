## Universal Installer (`install.sh`) Flags

The universal installer (`install.sh`) accepts flags to customize setup:

```bash
curl -fsSL https://gettako.dev/install.sh | bash -s -- [FLAGS]
```

### Supported Flags:

| Flag | Long Flag | Description |
| :--- | :--- | :--- |
| `-a` | `--agent` | Install in Worker Agent mode (instead of Master Server). |
| `-t <token>` | `--token <token>` | Provide the master enrollment token (required for worker nodes). |
| `-m <addr>` | `--master <addr>` | Specify master gRPC address (e.g. `198.51.100.10:50051`). |
| `-e <email>` | `--email <email>` | Admin email for initial master account setup. |
| `-p <pass>` | `--password <pass>` | Admin password for master account setup. |
| `-b <branch>` | `--branch <branch>` | Git branch to clone during source build (default: `main`). |
| `-d <dir>` | `--dir <dir>` | Target installation directory on host (default: `/opt/tako`). |

## Remote Deployer (`deploy.sh`)

For developers deploying directly from a local development machine to a remote VPS:

```bash
# 1. Copy example deployment configuration
cp .env.deploy.example .env.deploy

# 2. Edit .env.deploy with remote SSH credentials
nano .env.deploy

# 3. Execute remote synchronization & build
./deploy.sh
```

## Operational Docker Compose Commands

All Tako services on the host run inside `/opt/tako`:

```bash
# Check service health
cd /opt/tako && docker compose ps

# View real-time logs of a specific component
cd /opt/tako && docker compose logs -f server
cd /opt/tako && docker compose logs -f agent
cd /opt/tako && docker compose logs -f console
cd /opt/tako && docker compose logs -f traefik

# Stop the Tako stack
cd /opt/tako && docker compose down

# Restart the Tako stack
cd /opt/tako && docker compose up -d
```
