# 5-Minute Quickstart

Follow these steps to deploy the Tako Master stack and launch your first containerized application.

### Step 1: Run the Master Installer

On a clean Linux server or VPS (Ubuntu 22.04+, Debian 12+, AlmaLinux/Rocky 9+, Alpine Linux), run the universal installer:

```bash
curl -fsSL https://gettako.dev/install.sh | bash
```

The script will automatically:
1. Verify root / sudo privileges and detect CPU architecture (`amd64` / `arm64`).
2. Verify or auto-install Docker Engine and Docker Compose v2.
3. Detect host public and private IP addresses.
4. Prompt for administrator email, password, and public IP (or use environment variable overrides).
5. Initialize `/etc/tako/traefik` configuration, create the `tako-network` bridge, and launch the 4 master containers (`tako-traefik`, `tako-server`, `tako-console`, `tako-agent`).

### Step 2: Access the Console Dashboard

Once installation finishes, open your browser and navigate to:

```text
http://<YOUR_SERVER_IP>:3000
```

<Note>
Tako Console runs directly on port `3000` to prevent collisions with user application traffic on ports `80` and `443`. Traefik also configures a low-priority fallback router on ports `80` and `443` directing unmatched requests to the console.
</Note>

Log in with your administrator credentials configured during installation. You can immediately register a **Passkey (WebAuthn)** or enable **2FA** from your user profile settings.

### Step 3: Create a Project and Deploy a Service

In Tako, applications are organized under **Projects** (such as Production or Staging):

1. From the dashboard, select or create a **Project**.
2. Click **New Service**.
3. Choose your service type:
   - **Application**: Standalone container from a Docker Registry (e.g. Docker Hub, GHCR) or Git repository via GitHub App.
   - **Database**: Dedicated database service (PostgreSQL, MySQL, Redis, MongoDB).
   - **Compose**: Multi-container stack via `docker-compose.yml`.
4. Enter a service name (e.g. `web-app`), target container port (e.g. `80`), and Docker image (e.g. `nginxdemos/hello:latest`).
5. Configure your domain:
   - **Production Custom Domain**: e.g. `app.yourdomain.com` (Tako automatically provisions Let's Encrypt TLS certificates).
   - **Preview Wildcard Domain**: e.g. `app.<SERVER_IP>.sslip.io` (plain HTTP routing for immediate testing without DNS setup).
6. Click **Deploy**.

Tako streams the real-time build and deployment logs directly in the console through Server-Sent Events (SSE). Once healthy, Traefik immediately begins serving your application traffic!
