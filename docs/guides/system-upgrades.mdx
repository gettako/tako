## Checking for Updates

Tako automatically checks for new releases on GitHub:

1. In the Tako Console, go to **Settings** > **System**.
2. Click **Check for Updates** (calls `/api/v1/system/version/check`).
3. If a new version is available, the release notes and version tag will be displayed.

---

## Performing an Upgrade

Because Tako's state is stored in `/opt/tako/data/tako.db`, upgrading the control plane preserves all projects, services, domains, and secrets:

### 1. Master Server Upgrade

SSH into the master server and re-run the universal installer:

```bash
cd /opt/tako
curl -fsSL https://gettako.dev/install.sh | bash
```

Alternatively, pull the latest images using Docker Compose:

```bash
cd /opt/tako
docker compose pull
docker compose up -d
```

### 2. Worker Node Upgrade

On each worker node:

```bash
cd /opt/tako
docker compose pull
docker compose up -d
```

The updated agent will automatically reconnect to the master server and resume task processing without dropping any running user workload containers!
