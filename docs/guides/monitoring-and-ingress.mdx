## Real-Time Cluster Telemetry

Tako gathers real-time host and container performance statistics without external agent daemons (such as Prometheus node_exporter or Datadog):

- **Dashboard Charts:** Adaptive charts showing aggregate CPU, memory, and disk usage across the entire cluster.
- **Node-Level Health:** View per-node core counts, load averages, RAM saturation, disk capacity, and gRPC ping latency in the **Nodes** view.
- **Service-Level Metrics:** In the Service overview, monitor per-container memory usage and CPU throttling.

## Ingress Traffic Logs Inspector

Traefik captures access logs for all incoming HTTP/HTTPS traffic. Tako exposes these logs in the **Monitor** view:

### Filtering Ingress Logs:
- **Rate Options:** Filter by `50/s`, `100/s`, `500/s`, or live stream.
- **Status Code Filters:** Inspect only errors (`4xx`, `5xx`) or successful traffic (`2xx`).
- **Domain & Service Filter:** Isolate traffic directed to specific applications.

### Log Detail Sheet:
Clicking on any log entry slides open a detailed inspection sheet showing:
- Client IP address and Country Geolocation.
- Request Path, Query Parameters, and HTTP Method.
- User-Agent header and Referrer.
- TLS Version and Cipher Suite.
- Upstream duration (backend response time in milliseconds).
