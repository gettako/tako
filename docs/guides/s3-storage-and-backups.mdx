## Overview

Tako includes native support for backing up its SQLite control plane database, service configurations, and environment secrets to any **S3-compatible object storage** (AWS S3, Cloudflare R2, MinIO, Wasabi, DigitalOcean Spaces, Backblaze B2).

---

## Configuring S3 Storage

1. In the Tako Console, navigate to **Settings** > **S3 Storage**.
2. Click **Configure S3 Bucket** and enter:
   - **Endpoint:** (e.g. `https://s3.us-east-1.amazonaws.com` or `https://<account-id>.r2.cloudflarestorage.com`)
   - **Bucket Name:** e.g. `tako-cluster-backups`
   - **Region:** e.g. `us-east-1` or `auto`
   - **Access Key ID:** Your S3 access key
   - **Secret Access Key:** Your S3 secret key
   - **Force Path Style:** Toggle ON for MinIO / self-hosted S3

### Testing S3 Connection

Before saving, click the **Test Connection** button:
- Tako will send a test probe request to `/api/v1/settings/s3/test`.
- If credentials and bucket permissions are valid, a green confirmation badge appears.

---

## Creating & Scheduling Backups

1. Go to **Settings** > **Backups**.
2. Click **Create Backup Now** to take an instant atomic snapshot of the SQLite WAL database.
3. Configure automated backup schedules:
   - Frequency: Daily, Weekly, or Custom Cron.
   - Retention policy: Keep the last 7 daily and 4 weekly snapshots.
4. Backups can be downloaded locally as `.db.gz` archives or restored directly with a single click.
