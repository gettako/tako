## DNS Configuration

To route traffic to your services hosted on Tako, create a DNS record in your domain registrar or DNS provider (Cloudflare, Route53, Namecheap, etc.):

### 1. Specific Subdomain (e.g., `api.example.com`)
```text
Type:  A
Name:  api
Value: <YOUR_NODE_PUBLIC_IP>
TTL:   Auto / 300
```

### 2. Apex / Root Domain (e.g., `example.com`)
```text
Type:  A
Name:  @
Value: <YOUR_NODE_PUBLIC_IP>
TTL:   Auto / 300
```

### 3. Wildcard Subdomains (e.g., `*.example.com`)
```text
Type:  A
Name:  *
Value: <YOUR_NODE_PUBLIC_IP>
TTL:   Auto / 300
```

## Adding Domains in Tako Console

1. Navigate to your Service in the Console.
2. Select the **Settings** tab and go to **Domains**.
3. Click **Add Domain** and enter your fully qualified domain name (e.g. `app.example.com`).
4. Optionally enable **Enforce HTTPS Redirect** (automatically redirects all `http://` traffic to `https://`).
5. Click **Save Domain**.

## How Automatic SSL/TLS Works

Tako manages certificates via Traefik v3's built-in Let's Encrypt ACME resolver:

1. **ACME HTTP-01 Challenge:** When traffic first arrives for the domain, Traefik automatically requests a certificate from Let's Encrypt.
2. **Challenge Verification:** Let's Encrypt queries your domain on port `80` to verify ownership.
3. **Certificate Storage:** The certificate is saved securely in `/etc/tako/traefik/acme.json` (permission `600`).
4. **Auto-Renewal:** Traefik checks certificates daily and automatically renews them 30 days before expiration. Zero manual cron jobs or `certbot` commands required!
