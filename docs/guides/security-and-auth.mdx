## Role-Based Access Control (RBAC)

Tako enforces granular permissions across the control plane:

| Role | Permissions |
| :--- | :--- |
| **Admin** | Full system control: Manage cluster nodes, cluster settings, S3 backups, delete services, invite users, update credentials, system updates. |
| **Operator** | Service operations: Deploy services, restart containers, manage environment variables, view runtime logs and container terminals. |

---

## Passkey & WebAuthn (FIDO2) Authentication

Tako supports passwordless, phishing-resistant authentication using the WebAuthn standard:

1. Log into your account and navigate to **Profile** > **Passkeys**.
2. Click **Register New Passkey**.
3. Follow your browser/OS prompt to authorize via Touch ID, Face ID, Windows Hello, or hardware security keys (YubiKey).
4. On future logins, click **Sign in with Passkey** for instant, secure authentication.

---

## Team Invitations

Admins can invite team members with secure one-time invite tokens:

1. Go to **Settings** > **Users**.
2. Click **Invite User**.
3. Enter their email address and select their assigned role (`Admin` or `Operator`).
4. Tako generates a unique, cryptographically signed invite link with an expiration timeout.
5. The invited user opens the link, sets their password or registers a Passkey, and joins the cluster.

---

## Security Audit Logs

Tako logs every sensitive control plane action in an immutable audit trail:
- User logins and failed password attempts.
- Service creations, deletions, and configuration changes.
- Rollbacks and deployment triggers.
- Environment variable updates.

View the audit timeline anytime under **Audit Logs** in the Console.
