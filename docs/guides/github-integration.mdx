## Overview

Tako features an official **GitHub App Manifest** integration. Instead of creating personal access tokens (PAT) or managing individual SSH keys for every repository:

1. You create and install a dedicated GitHub App in your GitHub account or organization with 1 click.
2. Tako automatically gains read access to your chosen repositories.
3. Push events to specified branches automatically trigger deployments on Tako.

---

## Setting Up the GitHub App

1. In the Tako Console, go to **Settings** in the sidebar.
2. Click the **Git Integration** panel.
3. Click **Connect GitHub App**.
4. Tako generates a pre-configured GitHub App Manifest specifying required permissions:
   - Repository metadata: `Read-only`
   - Repository contents: `Read-only`
   - Webhooks: `Read & Write`
5. You are redirected to GitHub to authorize the app. Choose whether to grant access to:
   - **All repositories**, or
   - **Only select repositories**.
6. After authorization, GitHub redirects back to your Tako Console with the App ID and Private Key automatically saved in your secure database.

---

## Deploying a GitHub Repository

Once connected:

1. Go to any Project and click **Add Service**.
2. Select the **GitHub** tab.
3. You will see an instant searchable dropdown of all repositories in your account/organization.
4. Select the repository and choose the default branch (e.g. `main`).
5. Select whether to enable **Automatic Deployments on Push**.
6. Click **Deploy**.

---

## Automatic Webhook Deployments

When a developer pushes a new commit to the configured branch:
1. GitHub dispatches a `push` webhook to `https://<YOUR_TAKO_URL>/api/v1/github/webhook`.
2. Tako verifies the webhook HMAC signature using the configured secret.
3. The master server queues a new deployment for the service, checks out the exact Git commit SHA, and streams the build live!
