## 1. Worker Agent Fails to Connect to Master

**Symptoms:** Worker node status shows **Offline** or connection timeouts in agent logs.

### Check List:
1. **Firewall on Master:** Ensure inbound port `50051` is open on the master server:
   ```bash
   sudo ufw allow 50051/tcp
   # or on iptables / security groups
   ```
2. **Verify Master IP & Token:**
   Check the worker `.env` file in `/opt/tako/.env` and verify `TAKO_MASTER_URL` and `TAKO_AGENT_TOKEN`.
3. **Inspect Agent Logs:**
   ```bash
   cd /opt/tako && docker compose logs -f agent
   ```

---

## 2. Deployment Fails on Health Check

**Symptoms:** Deployment status marks **Failed** and rolls back after build succeeds.

### Check List:
1. **Health Check Path:** Verify the path exists in your application (e.g. `/health` or `/api/health`).
2. **Internal Port Mapping:** Ensure the internal container port matches what your app listens on (e.g. `3000` vs `8080`).
3. **Listen Address:** Make sure your application binds to `0.0.0.0` inside the container, **not** `127.0.0.1` (localhost)!

---

## 3. SSL / Let's Encrypt Certificate Pending

**Symptoms:** Domain routes over HTTP but HTTPS displays a certificate warning or timeout.

### Check List:
1. **DNS Resolution:** Verify that your domain's `A` record points directly to the server's public IP address.
2. **Port 80 Open:** Let's Encrypt HTTP-01 challenge requires inbound port `80` to be open from the internet.
3. **Inspect Traefik Logs:**
   ```bash
   cd /opt/tako && docker compose logs -f traefik
   ```
