## Overview

Stateful services (such as databases and object stores) require persistent storage so that data survives container restarts and upgrades.

---

## Deploying a Database (e.g. PostgreSQL)

You can deploy databases using pre-built images or Docker Compose:

### 1. Docker Image Method
1. Click **Create Service**.
2. Select **Docker Image**: `postgres:16-alpine`.
3. Add Environment Variables:
   ```text
   POSTGRES_DB=mydb
   POSTGRES_USER=myuser
   POSTGRES_PASSWORD=mysecurepassword
   ```
4. Define a persistent storage mount:
   ```text
   Volume: pgdata -> /var/lib/postgresql/data
   ```
5. Click **Deploy**.

---

## Connecting Applications to Databases

When your database and application service reside in the same project, Tako places them on the same isolated bridge network (`tako-network`).

You can connect directly using the container or service name:

```text
DATABASE_URL=postgres://myuser:mysecurepassword@mydb-service:5432/mydb
REDIS_URL=redis://myredis-service:6379
```

This connection travels entirely across the internal Docker network and is never exposed to the public internet!
