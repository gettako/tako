# Monitoring & Logs Guide

Tako provides end-to-end visibility into your infrastructure and running applications without requiring external agents like Datadog or Prometheus.

## Real-Time Node Telemetry

Every `tako-agent` collects hardware and container metrics directly via `gopsutil` and Docker Engine SDK:

- **CPU Utilization**: Real-time percent load across all cores.
- **Memory Consumption**: Used vs total megabytes.
- **Disk Space**: Used vs total gigabytes on root and data partitions.
- **Network I/O**: Real-time ingress (`Rx`) and egress (`Tx`) kilobits per second.
- **Node Status**: Automatically detects network partitioning or daemon failure within 15 seconds.

Metrics are pushed every 3 seconds to the Master Server and broadcast to the browser via Server-Sent Events (`/api/v1/events/nodes`).

### Historical Time-Series Aggregation
In addition to live telemetry, the master server automatically aggregates periodic snapshots into the `node_metrics` SQLite store. In the console's **Monitoring** view (`/monitoring`), you can inspect time-series charts across selectable ranges:
- `1h`: High-resolution 1-hour view.
- `6h`: 6-hour trend view.
- `24h`: 24-hour day overview.
- `7d`: 7-day multi-day resource utilization.

## Real-Time Audit Logs

Tako features a built-in tamper-resistant audit trail (`/audit-logs`) that records every critical cluster activity:
- Project creation and deletion.
- Service deployment triggers, rollbacks, and configuration edits.
- Node registrations and heartbeat status transitions.
- Cluster settings changes (S3 backups, Git integrations, TLS configurations).

Audit logs capture the initiating actor, IP address, timestamp, target resource, and full metadata payload.

---

## Live Build & Deployment Logs

During deployment, log chunks are streamed over gRPC from the agent directly to the master server's event bus.

In the console, you can monitor the live log stream in real time. The console log viewer supports:
- Automatic auto-scroll (Follow mode) to the latest log line.
- Real-time step grouping (Queued, Clone, Build, Push/Load, Deploy, Health check, Live).
- Full text search across log output.
- One-click copy of full compiler output.
- Historical log inspection (`/api/v1/deployments/:id/logs/history`).

---

## Container Runtime Logs

To view runtime output from live application containers:
1. Navigate to your **Service**.
2. Click the **Logs** tab.
3. Tako streams the `stdout` and `stderr` streams directly from the container's Docker socket.
