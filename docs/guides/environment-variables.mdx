## Managing Service Variables

Environment variables are passed directly into your container runtime when the container starts.

To manage environment variables:

1. Open your Service and click the **Environment** tab.
2. Tako provides two editing modes:
   - **Table View:** Structured Key-Value inputs with individual variable toggles and delete buttons.
   - **Raw .env View:** Standard multi-line editor for bulk pasting existing `.env` files.

---

## Secret Masking & Protection

To protect sensitive API tokens, private keys, and database passwords from shoulder-surfing or accidental screen shares:

- Values containing keywords like `SECRET`, `PASSWORD`, `KEY`, `TOKEN`, or `AUTH` are automatically masked by default.
- Click the **Reveal (Eye icon)** to temporarily view the decrypted value.
- Sensitive environment variables are encrypted at rest in the SQLite database before being committed to disk.

---

## Variable Precedence & Interpolation

You can reference platform-provided variables in your environment definitions:

```text
DATABASE_URL=postgres://user:pass@db:5432/main
PORT=3000
NODE_ENV=production
TAKO_SERVICE_ID=srv_xyz123
```

When you save changes to environment variables, Tako prompts you to trigger a zero-downtime redeployment so the new container version picks up the updated values immediately.
