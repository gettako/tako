# Tako Master REST API

The Tako Master Server exposes a high-performance RESTful API built on Go and Chi router for automation, CI/CD pipelines, and console interaction.

## Interactive Specification

The complete OpenAPI 3.1 specification is available at [`/openapi.yaml`](/openapi.yaml).

## Base URLs

- **Local Development**: `http://localhost:8080`
- **Next.js Console BFF**: `http://localhost:3000/api`
- **gRPC Server**: `localhost:50051`

---

## Authentication

All protected endpoints under `/api/v1` require authentication via Bearer token:

```http
Authorization: Bearer <your-jwt-token>
```

When accessed via the Next.js Console, session tokens are securely handled through `HttpOnly` cookies and forwarded by the BFF proxy.

### 2. Authentication (`/api/v1/auth`)

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/v1/auth/login` | Authenticate with email & password |
| `POST` | `/api/v1/auth/passkey/login` | Authenticate using WebAuthn Passkey |
| `POST` | `/api/v1/auth/logout` | Terminate session |
| `GET` | `/api/v1/auth/me` | Fetch profile for current authenticated user |
| `PUT` | `/api/v1/auth/profile` | Update user name, email, or avatar |
| `PUT` | `/api/v1/auth/password` | Change user password |
| `PUT` | `/api/v1/auth/2fa` | Enable or disable two-factor authentication |
| `GET` | `/api/v1/auth/passkeys` | List registered WebAuthn credentials |
| `POST` | `/api/v1/auth/passkeys` | Register a new passkey credential |
| `DELETE` | `/api/v1/auth/passkeys/{id}` | Delete a passkey credential |
| `GET` | `/api/v1/auth/sessions` | List active user login sessions |
| `DELETE` | `/api/v1/auth/sessions/{id}` | Terminate a specific session |
| `POST` | `/api/v1/auth/sessions/revoke-others` | Revoke all other active sessions |
| `GET` | `/api/v1/auth/users` | List cluster administrator users |
| `POST` | `/api/v1/auth/users` | Create a new user |
| `PUT` | `/api/v1/auth/users/{id}/role` | Update user role |
| `DELETE` | `/api/v1/auth/users/{id}` | Delete a user |

### 3. Nodes Management (`/api/v1/nodes`)

| Method | Endpoint | Description |
| :--- | :--- | :--- |

| `POST` | `/api/v1/nodes/{id}/reboot` | Dispatch remote host reboot via sysrq-trigger |
| `DELETE` | `/api/v1/nodes/{id}` | Delete and unenroll node from cluster |
| `GET` | `/api/v1/nodes/{id}/traefik` | Get node Traefik configuration settings |
| `PUT` | `/api/v1/nodes/{id}/traefik` | Update node Traefik settings |
| `POST` | `/api/v1/nodes/{id}/traefik/reload` | Hot reload Traefik configuration on node |
| `GET` | `/api/v1/nodes/{id}/traefik/files` | List all Traefik files on node |
| `GET` | `/api/v1/nodes/{id}/traefik/files/{filename}` | Read file content (`traefik.yml` or dynamic) |
| `PUT` | `/api/v1/nodes/{id}/traefik/files/{filename}` | Save Traefik configuration file content |
| `DELETE` | `/api/v1/nodes/{id}/traefik/files/{filename}` | Delete a dynamic routing file |
