Tako is an open-source, self-hosted platform for deploying applications to virtual private servers (VPS). It provides a personal deployment dashboard backed by an efficient Go control plane and dynamic Traefik v3 routing.

## Who Tako Is For

Tako is designed for solo developers, founders, and small engineering teams who want:

- Infrastructure ownership without vendor lock-in or recurring per-seat hosting fees.
- Automated deployments triggered from GitHub on branch pushes or pull requests.
- Multi-server cluster management coordinated from a central control plane.
- Outbound-only agent connectivity that avoids opening SSH port 22 or management ports on worker nodes.
- Automated Let's Encrypt SSL certificates and zero-downtime cutover gates via Traefik v3.
- Predictable container builds based on standard `Dockerfile` and `docker-compose.yml` definitions.

For an in-depth breakdown of how Tako compares to other infrastructure tooling, read our [Architectural Comparison: Dokploy vs. Kubernetes vs. Swarm vs. Tako](/why-tako#architectural-comparison-dokploy-vs-kubernetes-vs-swarm-vs-tako).

## Core Capabilities

The capabilities below reflect the active features implemented in the Tako codebase:

- **Git-driven deployments:** Connect GitHub repositories via the Tako GitHub App and trigger automated builds on commit pushes.
- **Dockerfile and Compose stacks:** Deploy single services or multi-container stacks defined with standard Docker Compose syntax.
- **Multi-server orchestration:** Attach remote worker nodes across different cloud providers using temporary, one-time enrollment tokens.
- **Outbound-only agent streams:** Manage remote worker nodes over persistent gRPC with TLS without opening inbound firewall ports.
- **Zero-downtime cutover:** Validate new containers against HTTP health check gates before switching traffic routes in Traefik.
- **One-click rollbacks:** Revert to previous successful container image tags in seconds without rebuilding from source.
- **Automated SSL and routing:** Provision Let's Encrypt certificates automatically via Traefik v3 and manage custom domain routing.
- **Auxiliary services:** Run background workers and cron jobs that share the built application image.
- **Managed database templates:** Provision PostgreSQL, MySQL, and Redis services with persistent Docker volumes.
- **Pull request previews:** Automatically spin up ephemeral staging environments with wildcard subdomains for pull requests.
- **Encrypted configuration:** Store runtime environment variables and build arguments encrypted at rest with AES-256-GCM.
- **Real-time log streaming:** Monitor Docker image build progress and live container stdout/stderr through Server-Sent Events (SSE).
- **Web terminal access:** Open interactive shell sessions directly into running containers from the web console.
- **S3 backups:** Schedule database dumps and volume archives to S3-compatible object storage.
- **Audit logging:** Immutable activity audit trail with ULID ordering and actor attribution for every mutation.
- **Team collaboration:** Manage team access with flat role-based access control (`admin` and `member`).
