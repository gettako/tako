# Manual Docker Compose Setup

If you prefer full control over your container deployment rather than using `install.sh`, you can use the official `docker-compose.yml` templates.

## Master Node `docker-compose.yml`

Create a directory `tako` and save the following as `docker-compose.yml`:

```yaml
services:
  traefik:
    image: traefik:v3.1
    container_name: tako-traefik
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock:ro
      - ./traefik/traefik.yml:/etc/traefik/traefik.yml:ro
      - ./traefik/acme.json:/acme.json
    environment:
      - TAKO_ACME_EMAIL=admin@example.com
    networks:
      - tako-network

  server:
    image: ghcr.io/gettakodev/tako-server:latest
    container_name: tako-server
    restart: unless-stopped
    ports:
      - "50051:50051"
      - "127.0.0.1:8080:8080"
    volumes:
      - ./data/sqlite:/data
    environment:
      - TAKO_HTTP_PORT=8080
      - TAKO_GRPC_PORT=50051
      - TAKO_DB_PATH=/data/tako.db
      - TAKO_AUTH_SECRET=super-secret-random-jwt-key
      - TAKO_INITIAL_ADMIN_EMAIL=admin@example.com
      - TAKO_INITIAL_ADMIN_PASSWORD=adminpassword
    networks:
      - tako-network

  console:
    image: ghcr.io/gettakodev/tako-console:latest
    container_name: tako-console
    restart: unless-stopped
    ports:
      - "3000:3000"
    environment:
      - TAKO_SERVER_URL=http://tako-server:8080
      - NEXT_PUBLIC_TAKO_SERVER_URL=http://localhost:3000
    depends_on:
      - server
    networks:
      - tako-network

  agent:
    image: ghcr.io/gettakodev/tako-agent:latest
    container_name: tako-agent
    restart: unless-stopped
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
      - ./data/agent:/data
    environment:
      - TAKO_SERVER_ADDR=tako-server:50051
      - TAKO_ENROLL_TOKEN=local-master-token
      - TAKO_NODE_NAME=tako-master-01
      - TAKO_METRICS_INTERVAL=3s
    depends_on:
      - server
    networks:
      - tako-network

networks:
  tako-network:
    name: tako-network
    driver: bridge
    attachable: true
```

Start the master stack:

```bash
docker compose up -d
```
