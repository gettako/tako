# Master Server Installation

The Master Server hosts the Tako control plane, pure-Go SQLite database, Next.js web console, local agent daemon, and Traefik reverse proxy.

## System Requirements

- **Operating System**: Ubuntu 22.04+, Debian 12+, Rocky/Alma Linux 9+, or Alpine Linux
- **Architecture**: `amd64` (x86_64) or `arm64` (aarch64)
- **RAM**: 1 GB minimum (2 GB+ recommended for production)
- **CPU**: 1 Core minimum (2+ Cores recommended)
- **Disk**: 10 GB SSD minimum
- **Inbound Ports**:
  - `80/tcp` & `443/tcp`: Ingress HTTP/HTTPS routing via Traefik
  - `3000/tcp`: Direct Tako Console Dashboard access
  - `50051/tcp`: gRPC Control Hub for Worker Nodes
  - *Note: `8080/tcp` is the internal REST API, bound to `127.0.0.1:8080` by default.*

---

## Interactive Installation

Run the universal installer as root or with sudo:

```bash
curl -fsSL https://gettako.dev/install.sh | bash
```

The script will prompt you for:
- **Admin Email**: Used for console login and Let's Encrypt certificate notices (default: `admin@gettako.dev`).
- **Admin Password**: Your initial administrator password.
- **Server Public IP**: Auto-detected from external resolvers or customizable.
- **Server Private IP**: Internal interface IP for local cluster communication.

## Non-Interactive / Automated Setup

For automated provisioning (e.g. Terraform, Ansible, cloud-init), supply environment variables ahead of time:

```bash
export TAKO_EMAIL="admin@example.com"
export TAKO_PASSWORD="your-secure-password"
export TAKO_AUTH_SECRET="a-32-byte-random-jwt-secret-key"
export TAKO_PUBLIC_IP="203.0.113.10"
export TAKO_PRIVATE_IP="10.0.0.5"
export TAKO_DIR="/opt/tako"

curl -fsSL https://gettako.dev/install.sh | bash
```

### Supported Environment Variables

| Variable | Description | Default |
| :--- | :--- | :--- |
| `TAKO_EMAIL` | Initial admin account email | Prompted / `admin@gettako.dev` |
| `TAKO_PASSWORD` | Initial admin account password | Prompted / `admin123456` |
| `TAKO_AUTH_SECRET` | 32-character secret key for JWT signing | Randomly generated |
| `TAKO_PUBLIC_IP` | Public IPv4 address for ingress | Auto-detected |
| `TAKO_PRIVATE_IP` | Internal IPv4 address for gRPC/Docker | Auto-detected |
| `TAKO_DIR` | Root folder for Docker Compose and data | `/opt/tako` |

## Directory Structure & Filesystem Layout

Tako organizes configuration and data across two primary locations on the host:

```text
/opt/tako/
├── docker-compose.yml       # Active compose manifest for master containers
└── data/
    ├── sqlite/
    │   └── tako.db          # Pure-Go SQLite database in WAL mode
    └── agent/
        └── agent.json       # Agent local state & enrollment metadata

/etc/tako/traefik/
├── traefik.yml              # Static Traefik config (entrypoints, ACME, providers)
├── tako.yml                 # Console fallback routing on ports 80/443 (priority: 1)
├── acme.json                # Let's Encrypt TLS certificate storage (chmod 600)
└── dynamic/                 # Dynamic YAML files generated by Tako Agent
    └── <service-slug>.yml   # Real-time routing rules per user service
```

The Traefik dynamic configuration folder `/etc/tako/traefik/dynamic` is monitored continuously by Traefik's file provider, enabling zero-downtime routing updates whenever services are deployed or removed.
