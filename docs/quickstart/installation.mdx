## System Requirements

Tako runs on standard modern Linux distributions with Docker Engine installed.

| Component | Minimum | Recommended |
| :--- | :--- | :--- |
| **Operating System** | Linux (Ubuntu 22.04+, Debian 12+, Rocky/AlmaLinux 9+, Alpine 3.19+) | Ubuntu 24.04 LTS or Debian 12 |
| **Architecture** | x86_64 (`amd64`) or ARM64 (`aarch64`) | `amd64` or `arm64` |
| **CPU** | 1 vCPU | 2 vCPU |
| **RAM** | 512 MB (Master control plane idles under 50 MB) | 2 GB or more (for user workload builds) |
| **Storage** | 10 GB SSD / NVMe | 25 GB SSD |
| **Docker Engine** | Docker 24.0+ & Docker Compose v2 | Docker 26.0+ |

<Note>
If Docker Engine or Docker Compose v2 are not installed on your host, the universal installer script will automatically install and configure them for you.
</Note>

## Network & Firewall Setup

### Master Node Ports

| Port | Protocol | Direction | Purpose | Access Level |
| :--- | :--- | :--- | :--- | :--- |
| **80** | TCP | Inbound | HTTP traffic and ACME Let's Encrypt challenges | Public Internet |
| **443** | TCP | Inbound | HTTPS web traffic, Tako Console, and deployed apps | Public Internet |
| **50051** | TCP | Inbound | gRPC endpoint for worker agent multiplexed connections | Public or Worker IPs |
| **22** | TCP | Inbound | SSH server management (host administration) | Restricted / VPN |

### Worker Node Ports

| Port | Protocol | Direction | Purpose | Access Level |
| :--- | :--- | :--- | :--- | :--- |
| **80** | TCP | Inbound | HTTP ingress traffic for hosted containers | Public Internet |
| **443** | TCP | Inbound | HTTPS ingress traffic and TLS termination | Public Internet |
| **50051** | TCP | **Outbound** | Persistent gRPC connection to Master Server | Destination: Master IP:50051 |

<Important>
Worker nodes **do not require inbound port 50051 or inbound SSH port 22** open to the master server! The worker agent establishes an outbound connection to the master.
</Important>

## Step 1: Install the Master Server

SSH into your target master server as `root` (or with `sudo`), and execute the universal installer:

```bash
curl -fsSL https://gettako.dev/install.sh | bash
```

### Automated / Non-Interactive Installation

For automated provisioning (e.g. cloud-init, Ansible, or CI scripts), pass environment variables inline:

```bash
curl -fsSL https://gettako.dev/install.sh | TAKO_EMAIL="admin@yourdomain.com" TAKO_PASSWORD="your-secure-password" bash
```

### What the Installer Does:
1. Detects host operating system and architecture (`amd64` or `arm64`).
2. Checks for Git, Docker Engine, and Docker Compose v2 (installs them automatically if missing).
3. Auto-detects public and private IP addresses.
4. Generates cryptographically secure secrets (`TAKO_AUTH_SECRET`, `TAKO_AGENT_SECRET`).
5. Creates runtime directories: `/opt/tako/data` and `/etc/tako/traefik/dynamic`.
6. Configures Traefik v3 reverse proxy with Let's Encrypt TLS support.
7. Launches the Tako Master stack (`tako-server`, `tako-console`, `tako-agent`, and `tako-traefik`).

Once installation finishes, the terminal displays your connection credentials:

```text
==================================================
Tako Master Server Installed Successfully!
==================================================
Console URL      : http://<SERVER_IP>:3000 (or https://<DOMAIN>)
Admin Email      : admin@yourdomain.com
Admin Password   : [Randomly Generated or Specified Password]
Enrollment Token : [32-Character Enrollment Secret]
Working Dir      : /opt/tako
==================================================
```

## Step 2: Open the Tako Console

Open your browser and navigate to:

```text
http://<YOUR_SERVER_IP>:3000
```

Log in using the administrator email and password from Step 1. You will be greeted by the Tako Platform Dashboard!

## Step 3: Connect Worker Nodes (Optional)

Tako can schedule workloads across multiple nodes. To connect a remote worker server:

1. Log into your worker server via SSH.
2. Run the installer with the `--agent` flag:

```bash
curl -fsSL https://gettako.dev/install.sh | bash -s -- \
  --agent \
  --token "<ENROLLMENT_TOKEN>" \
  --master "<MASTER_PUBLIC_IP>:50051"
```

Replace:
- `<ENROLLMENT_TOKEN>`: The enrollment token printed by the master installer (also visible in **Settings > Cluster** in the Console).
- `<MASTER_PUBLIC_IP>`: The public IP address or domain of your master server.

Within seconds, the worker agent registers with the master, and the new server appears as **Online** under the **Nodes** section in the Console!

## Common Management Commands

Tako services run in `/opt/tako` via standard Docker Compose:

```bash
# Check service status
cd /opt/tako && docker compose ps

# View master server logs
cd /opt/tako && docker compose logs -f server

# View edge proxy logs
cd /opt/tako && docker compose logs -f traefik

# View agent logs
cd /opt/tako && docker compose logs -f agent

# Restart the entire stack
cd /opt/tako && docker compose restart
```
