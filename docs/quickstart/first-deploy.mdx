## Overview

In this guide, you will deploy a web application to your Tako cluster using a Git repository or Docker image, configure custom routing, and verify automatic SSL certificate provisioning.

---

## Step 1: Create a Project

Tako organizes workloads into **Projects** with environment separation (`production`, `staging`, `preview`):

1. In the Tako Console, click **Projects** in the sidebar.
2. Click **Create Project**.
3. Enter a project name (e.g., `my-saas-app`) and select the target environment (`production`).
4. Select the target node (e.g. `tako-master-01` or any connected worker node).
5. Click **Create Project**.

---

## Step 2: Add a Service

Inside your project, click **+ Add Service** or select from the dropdown:

<Steps>
  <Step title="Choose Deployment Source">
    Select how you want to deploy your service:
    - **Public or Private Git Repository:** Provide a Git clone URL (HTTPS/SSH) and branch name (e.g. `main`).
    - **GitHub App:** Select directly from your connected GitHub account or organization repositories.
    - **Docker Image:** Pull directly from Docker Hub, GitHub Container Registry (`ghcr.io`), or private registries.
    - **Docker Compose:** Paste or upload multi-container compose definitions.
  </Step>

  <Step title="Configure Build Settings">
    Specify your build options:
    - **Build Type:** `Dockerfile`, `Docker Compose`, or `Nixpacks`.
    - **Port Mapping:** Internal container port (e.g., `3000` for Next.js/Node, `8080` for Go/Java, `8000` for Python/Django).
    - **Health Check Path:** Optional probe endpoint (e.g. `/health` or `/api/health`).
  </Step>

  <Step title="Set Domains & Environment Variables">
    - **Domain:** Add your custom domain (e.g., `app.yourdomain.com`). Traefik will automatically provision a free Let's Encrypt TLS certificate.
    - **Environment Variables:** Enter key-value pairs (e.g. `NODE_ENV=production`, `DATABASE_URL=...`). Sensitive values are masked automatically.
  </Step>

  <Step title="Click Deploy">
    Click **Deploy Service** to start the deployment pipeline!
  </Step>
</Steps>

---

## Step 3: Monitor Deployment Progress

Once triggered, navigate to the **Deployments** tab or **Runtime Logs** tab in your service view:

1. **Live Stream:** Watch real-time build logs streamed directly from the agent via Server-Sent Events (SSE).
2. **Container Launch:** The agent builds the Docker image and launches the container on an internal port.
3. **Health Check Gate:** The agent probes your application's health endpoint.
4. **Traffic Promotion:** Once healthy, Traefik atomically cuts over live traffic to the new container.

Your service is now live! Click the domain link in the service header to open your running application in your browser.

---

## Step 4: Interact with Your Container

Tako includes powerful operational tools built directly into the Console:

- **Web Terminal:** Open the **Terminal** tab to execute shell commands directly inside your running container with xterm.js and tab completion.
- **Runtime Logs:** Open the **Logs** tab to stream stdout/stderr output from your container.
- **Rollback:** If a future deployment fails, go to the **Deployments** tab and click **Rollback** on any previous deployment to instantly revert traffic.
