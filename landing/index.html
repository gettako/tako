Run your own deploy platform on your own servers.

Tako is a self-hosted deployment platform. A Go control plane schedules your containers onto worker nodes, Traefik routes traffic to them, and the console shows each deploy step as it happens.

deploy flow

one agent task
  1. 1 Clone or pull the repository agent
  2. 2 Build or pull the image docker
  3. 3 Write a preview route traefik
  4. 4 Start the new container docker
  5. 5 Health check docker

passes

Write the canonical route, prune old previews, report Live.

fails

Report Failed and roll back to the last healthy deployment.

Workers call the master. Never the other way round.

Agents do not accept inbound management connections. Each one dials out to the master over gRPC, runs Docker and Traefik work on its own host, and streams logs and task results back.

One control plane
State lives in SQLite on the master. Add as many worker nodes as you need.
Routing stays local
Each node's Traefik watches a route directory that its own agent writes to.
One origin for the browser
The console proxies /api/v1 to the server, so there is no CORS setup.

What the console and API cover

Everything below has a route in the server and a page in the console. Nothing here is on a roadmap.

Git or image deploys
Build from a repository or pull a ready image. Credentials for private registries are managed in the console.
GitHub App
Connect a GitHub App and receive webhook events. The receiver checks the signature when a webhook secret is set.
Domains and TLS
Attach custom domains per service. Traefik requests Let's Encrypt certificates with the HTTP challenge.
Environment variables
Set them per service from the console or the API.
Cron jobs
Schedule a command against a service. Each job shows its last run, next run, and last status.
Backups
Snapshot the database and service configuration. Each snapshot carries a checksum, and S3 or MinIO storage can be configured.
Logs and metrics
Deployment progress and container logs stream over server-sent events. Ingress access logs and node metrics have their own views.
Traefik editor
Edit a node's Traefik YAML and manage its route files from the console, then reload.
Access and audit
Invite teammates, keep admin actions behind the admin role, and review changes in the audit log.

Master first, then workers.

The installer adds git and Docker if they are missing, clones the repository into /opt/tako, and builds on the host. It supports amd64 and arm64.

For a worker, pass the enrollment token from your master node and the address of its gRPC port. 

curl -fsSL https://gettako.dev/install.sh | bash
curl -fsSL https://gettako.dev/install.sh | bash -s -- --agent --token <TOKEN> --master <MASTER_IP:50051>

Replace <TOKEN> and <MASTER_IP:50051> before running.
